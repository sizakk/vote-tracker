# VoteTracker 다중사용자 + Supabase 확장 PRD

## 프로젝트 개요
Excel 파일 업로드로 직원 제도변경 동의 현황을 확인하는 반응형 웹앱을 다중 사용자 시스템으로 확장하고, Supabase를 활용하여 성능을 최적화

## 기존 기능 유지
- 모든 UI 컴포넌트 (KPI 카드, 차트, 분석 버튼 등) **그대로 유지**
- 9개 분석 카테고리 로직 **그대로 유지**
- 반응형 디자인 **그대로 유지**
- 차트 라이브러리 (Recharts) **그대로 유지**

## 새로 추가되는 기능

### 1. 사용자 인증 시스템 (초간단)
- **로그인 방식**: 사번 입력만으로 로그인
- **사용자 구분**: 관리자 vs 일반 사용자
- **권한 관리**: 특정 사번에만 업로드 권한 부여

### 2. Supabase 데이터베이스 연동
- **JSON 파일 대신 DB 사용**: 성능 대폭 개선
- **실시간 데이터**: 관리자 업로드 시 모든 사용자에게 즉시 반영
- **효율적인 쿼리**: 3MB JSON → 5-20KB API 응답

### 3. AI 요약 분석 기능
- **OpenAI API 연동**: 분석 결과에 대한 AI 요약 제공
- **분석 카테고리별 인사이트**: 각 분석 결과에 대한 자동 해석

## 기술 스택 확장

### 기존 스택 (유지)
- Next.js (App Router) + TypeScript
- TailwindCSS + ShadCN
- Recharts (차트)
- SheetJS (Excel 파일 처리)

### 추가 스택
- **Supabase**: PostgreSQL 데이터베이스 + 실시간 기능
- **NextAuth.js**: 간단한 사번 기반 인증
- **OpenAI API**: AI 분석 요약 기능

## 데이터베이스 스키마

### 1. employees 테이블
```sql
CREATE TABLE employees (
  id SERIAL PRIMARY KEY,
  employee_id VARCHAR(20) NOT NULL,
  category VARCHAR(50),
  major_org VARCHAR(100),
  organization VARCHAR(200),
  name VARCHAR(50),
  grade VARCHAR(10),
  grade_year INTEGER,
  position VARCHAR(50),
  years_of_service DECIMAL(3,1),
  hiring_type VARCHAR(50),
  gender VARCHAR(10),
  age INTEGER,
  is_implemented BOOLEAN DEFAULT FALSE,
  implemented_date TIMESTAMP,
  agreement_status VARCHAR(10),
  is_confirmed BOOLEAN DEFAULT FALSE,
  confirmed_date TIMESTAMP,
  final_agreement VARCHAR(10),
  upload_batch_id UUID,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 2. allowed_users 테이블
```sql
CREATE TABLE allowed_users (
  employee_id VARCHAR(20) PRIMARY KEY,
  name VARCHAR(50),
  role VARCHAR(20) DEFAULT 'user', -- 'admin' or 'user'
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3. upload_batches 테이블
```sql
CREATE TABLE upload_batches (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  uploaded_by VARCHAR(20),
  upload_date TIMESTAMP DEFAULT NOW(),
  total_employees INTEGER,
  file_name VARCHAR(200)
);
```

## 사용자 플로우

### 일반 사용자
```
1. 사번 입력 로그인
2. 대시보드 자동 로딩 (실시간 데이터)
3. 분석 버튼 클릭
4. AI 요약 분석 확인
5. 비동의자 목록 조회
```

### 관리자
```
1. 사번 입력 로그인 (관리자 권한 확인)
2. 대시보드 확인 + 관리자 메뉴 접근
3. Excel 파일 업로드
4. 실시간으로 모든 사용자에게 반영
5. 업로드 이력 관리
```

### 2. 실시간 업데이트
```typescript
// Supabase 실시간 구독
const channel = supabase
  .channel('dashboard-updates')
  .on('postgres_changes', 
    { event: 'INSERT', schema: 'public', table: 'upload_batches' },
    () => {
      // 새 데이터 자동 새로고침
      toast.success('새로운 데이터가 업데이트되었습니다');
      refetchDashboardData();
    }
  );
```

### 3. 캐싱 전략
```typescript
// React Query로 데이터 캐싱

  ['dashboard-summary'],
```

## 보안 및 권한

### 1. Row Level Security (RLS)
```sql
-- 허가된 사용자만 데이터 조회 가능
CREATE POLICY "Users can view employees" ON employees
  FOR SELECT USING (
    EXISTS (
      SELECT 1 FROM allowed_users 
      WHERE employee_id = auth.jwt() ->> 'employee_id'
    )
  );
```

### 2. API 라우트 보호
```typescript
// 모든 API에 인증 미들웨어
export default withAuth(async function handler(req, res) {
  // 인증된 사용자만 접근 가능
});

// 관리자 전용 API
export default withAdminAuth(async function handler(req, res) {
  // 관리자만 접근 가능
});
```
